# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user input.

## Description
This project provides a command-line calculator that computes simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- **Principal** – the initial amount of money
- **Rate of Interest** – the annual interest rate (%)
- **Time Period** – the duration in years

## Output
The calculated simple interest based on the provided inputs.

## Usage
Run the script `simple-interest.sh` in a Bash terminal and enter the requested values when prompted.
